# dotfiles

macOS setup for web development on Apple silicon. Clone, then run in Terminal as your own user:

```sh
./setup.zsh
```

It asks before installing apps or applying opinionated settings. Without asking, it turns on Touch ID for `sudo`, the firewall and automatic macOS updates, plus a few developer defaults (`setup_*` in `setup.zsh`).

Safe to rerun. If it stops on an error, fix that and run it again.
